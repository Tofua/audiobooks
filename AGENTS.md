# Repo Guidance

This is Tofua's personal side project, not a Bull-Whip/work repository.

## GitHub

- Personal repo: `git@github.com-tofua:Tofua/audiobooks.git`
- Public URL: `https://github.com/Tofua/audiobooks`

## Git Identity

- Use the repo-local Git identity already configured in `.git/config`.
- Do not change global Git config.
- Keep work/company GitHub access separate.

## Operational Notes

- This repo intentionally uses the `github.com-tofua` SSH host alias.
- Avoid replacing the remote with raw `git@github.com:Tofua/audiobooks.git`, because that may route through the default/work GitHub identity.
